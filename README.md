# Проект ProjectBD
## Описание:
В данном проекте реализованы функции получения данных о компаниях и вакансиях по API сайта HeadHunter, а также создание 
и заполнение базы данных полученной информацией.
Реализован класс с методами для работы с данными, хранящимися в базе данных.
Также создана функция для взаимодействия с пользователем, которая объединяет все части проекта и формирует
человекочитаемые ответы на запросы пользователя.
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/vacancy_data
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. Для работы проекта необходим файл database.ini.
В репозитории присутствует файл database.ini.example. Перед запуском проекта необходимо создать файл database.ini и 
заменить значения переменных в соответствии с вашими данными для подключения к базе данных PostgreSQL.
6. Для создания базы данных используется модуль create_database.py, в котором реализована одноимённая функция 
create_database.
7. Модуль getting_data_API.py предназначен для получения данных о компаниях и вакансиях с сайта HeadHunter по исходному 
списку ID компаний.
8. В модуле save_data_to_database.py реализована функция для сохранения полученных данных в созданную базу данных.
9. В модуле DBManager.py реализован класс DBManager, который подключается к базе данных PostgreSQL и содержит методы 
для получения и обработки информации из базы данных.
10. Для формирования человекочитаемого вывода в главном модуле main.py создан модуль formatter.py с классом Formatter, 
который обрабатывает результаты работы методов класса DBManager.
## Тестирование:
Все тесты лежат в директории tests/, имена модулей начинаются с test_.
Для запуска тестирования необходимо установить pytest:
```
poetry add --group dev pytest
```
Запустить тесты можно через команду pytest в терминале:
```
pytest
```
